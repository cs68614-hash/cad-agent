# 架构与边界

```text
MCP 客户端（Windows/Mac/Web 客户端，能力各异）
        │ stdio 或 /mcp Streamable HTTP
        ▼
协议层：工具发现、结构化结果、Bearer/Host/Origin 校验
        ▼
Coordinator：目录、参数、文档绑定、路径、禁用策略
        ▼
单个 STA 执行线程 + 持久请求日志
        ├── daiemon 适配器 ─┐
        └── Hub 适配器 ────┴── 同一个已运行 CATIA V5 实例
```

## 不是两个服务器的拼接

两份上游都使用 `catia_mcp` 包名。本包分别置于 `automotive_catia.vendor.daiemon` 与 `automotive_catia.vendor.hub`，避免 import 冲突。工具名称使用来源前缀，名称相似的工具不会静默互相覆盖。上游服务器入口不是统一运行入口，禁止直接以 vendor/server.py 启动。

连接和 COM 对象必须留在单个 STA 线程。统一运行入口只连接已运行实例，不自动启动 CATIA；Hub 的上游调度器不再拥有独立执行线程。并发 MCP 请求不意味着并发修改同一零件。

## 文档绑定与请求日志

- `auto_connect` 连接已运行的 CATIA；`auto_session` 查询控制状态。
- `auto_bind_document(confirm_name)` 在核对当前文档名称后获得 `document_token`。
- 活动文档工具要求该 token；成功变更后使用结果中的 `next_document_token`，不能继续使用过期值。
- 修改工具还要求 `request_id`。请求摘要包含操作、规范化参数、会话/文档身份，同 ID 不同输入拒绝执行。
- SQLite 日志记录请求进度和结果。服务重启不能把旧会话的成功记录直接当成新 CATIA 会话已执行。

这些是防误用措施，不是多人协同事务。CATIA GUI、宏或其他插件可能在服务之外改变文档，无法靠 token 检出所有几何变化。应使用专门执行会话，避免人工同时编辑。

## 未知结果与部分修改

COM 超时不代表 CATIA 停止，客户端取消不等于撤销。异常发生前可能已创建部分特征，部分上游清理也可能失败。运行层把未知结果与普通校验失败分开，阻断后续修改，避免无脑重试。

`auto_acknowledge_unknown(acknowledge=true)` 仅记录调用者的恢复确认；只有工作线程空闲后才可能恢复。它不证明人工已检查、不撤销旧操作、不把旧未知记录改写成成功，也不提供 exactly-once 保证。需要根据 CATIA 对象树、原始参数、日志和预期几何判断是否补做、删除或恢复副本。

## 文件和网络边界

路径校验覆盖传入的读写路径；隐式 Save 也必须检查活动文档已有路径，不能绕过允许目录。符号链接解析有助于阻止目录逃逸，但这不是 OS 沙箱，也不能完全防止并发替换链接等 TOCTOU 风险。应让专用 Windows 用户仅拥有所需目录权限。

远程入口只接受限定 Host/Origin，非回环绑定要求 Bearer token。**Bearer 不加密流量。** 本程序不管理证书、VPN、防火墙、OAuth、多租户身份或权限隔离。多个获授权客户端共享一个 CATIA 会话；不要把它当公共 SaaS。

## 故意不提供

- 任意脚本、命令行、用户指定 COM 方法执行。
- 无限制文件访问、自动后台启动 CATIA、跨用户会话操作。
- 自动全局回滚、稳定 B-rep 身份、真实 G2/自交/成形合格判定。
- 已完成的通用仿真闭环：Analysis 基元存在，但材料引用、实体属性、边界条件、网格与结果物理有效性需要独立验证。

## 副作用分类细节

质量检查会调用 UpdateObject，因此归类为变更操作，必须有 request_id；更新/测量错误会让曲面流水线停止。材料目录查询会开关文档，拓扑/惯量查询可能改变 Selection/SPA 集合，亦保守纳入变更保护。任何变更后若活动文档不同于原绑定，令牌失效并要求明确重新绑定，不会自动把另一文档当作原目标。

## 独占运行及缓存边界

同一 CATIA Windows 用户会话只允许一个本服务进程；不要启动另一工作目录的服务来绕过忙碌/未知状态。同一journal文件的进程锁不提供跨workspace、跨程序的CATIA全局锁。外部宏、GUI、第三方插件不受此锁控制。

绑定到另一文档、变更引起活动文档切换或未知结果恢复后，会在STA线程丢弃文档级Sketcher/GSD缓存，不复用旧文档工厂。不会擅自对旧文档调用CloseEdition；切换前请完成/关闭草图编辑，异常遗留编辑需人工检查。
